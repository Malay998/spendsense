SPENDSENSE UPGRADE — THEMES + ACCOUNT SIGN-IN

WHAT'S NEW
- Eight visual themes: Midnight Lime, Ocean Blue, Aurora Violet, Rose Quartz, Amber Glow, Forest, Paper Light, and Monochrome.
- Theme choice applies immediately and is saved in the current browser/device.
- Sign in with either password or an email magic link.
- Create an account with email/password, request a password reset, and set/change a password from Settings.
- Supabase SSR cookies and middleware refresh the session on visits so users can return to their account until they sign out or the session expires.
- Better responsive layout and a sign-out control that remains available on mobile.
- Safe local-path validation on the auth callback redirect.
- Fixes for JSX apostrophes and unused imports seen in earlier build logs.

HOW TO APPLY THIS ZIP TO AN EXISTING WINDOWS PROJECT
1. Keep your existing project folder and its hidden .git folder.
2. Extract this ZIP. Open the extracted "spendsense" folder.
3. Copy the files and folders inside it into your existing project folder, for example:
   C:\Users\paulm\Downloads\spendsense-starter\spendsense
4. When Windows asks, choose to replace files in the destination.
5. Do NOT delete or replace your existing .env.local file. This ZIP intentionally does not contain it. Do NOT remove the .git folder.
6. Open VS Code in the existing project folder and run:
   npm.cmd run build
7. If the build succeeds, commit and push the changes to GitHub. Vercel should deploy the new commit automatically.

AUTH CONFIGURATION CHECK
In Supabase Dashboard > Authentication > URL Configuration, ensure your production site URL is your current Vercel production origin, and allow that origin's /auth/callback path. Keep http://localhost:3000/auth/callback for local development. If the deployed Vercel URL is different, use the exact current URL from Vercel.

SECURITY NOTES
- Keep .env.local out of GitHub.
- Never put a Supabase service-role/secret key in a NEXT_PUBLIC_ variable or browser code.
- Theme preference is local to each browser/device; it is not stored in the Supabase profile.
